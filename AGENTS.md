This is a repository of "skill" files used by agent harnesses.

By default, when you are developing in this repository and creating/editing a skill, always work _in this repo_ not on a globally installed skill file of the same name.

Test skills out (in a fresh subagent if possible) before calling them done.

Write skills as simply and minimally as possible.

You're working on main by default. No worktrees / branches expected unless told otherwise.
