# Write Simply

## Procedure

Author (skip if revising): write the answer in one sentence. Add only
what the reader needs to act on it. Stop.

Then run three passes. Each pass has one job. Do not do the next
pass's job early.

### Pass 1 — Cut

Write one private sentence: what the reader must decide or do.
Then, in order:

1. Delete paragraphs that do not serve it.
2. Delete sentences that do not serve it.
3. Delete words.

Do not rewrite anything in this pass. Only delete.
Target: 60% of source length or less.

### Pass 2 — Plain

Rewrite what survived:

- Plainer words: exact nouns, direct verbs, no metaphors for
  processes or states.
- Plainer grammar: one clause per sentence where possible.
  Subject-verb-object. Active voice.
- Plainer punctuation: periods. No em dashes, no semicolons,
  no colons introducing lists inside sentences.

Length may grow slightly here. That is fine.

### Pass 3 — Check

Answer these. If any answer is no, fix it and stop.

- Is every fact and qualification from the source still present?
- Does each idea appear exactly once?
- Is the answer in the first sentence?
- Is any sentence over 25 words?
- Does anything in "Never write" appear?

Do not make stylistic changes in this pass. If nothing fails,
return the text.
